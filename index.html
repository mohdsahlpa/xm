🚀 How to Use & Integration Guide

This application requires zero backend servers and works entirely with static files hosted on GitHub Pages:

1. In a Browser:
Navigate to https://mohdsahlpa.github.io/xm?id=1 to instantly view the C source code for program ID 1.

2. In Command Line / Curl / Wget:
Static files are directly retrievable via HTTP: curl -sL https://mohdsahlpa.github.io/xm/programs/1.c

3. Adding New C Programs:
Simply drop any new <id>.c file (e.g. 4.c, 5.c) into the programs/ folder and push to GitHub. It becomes immediately accessible at ?id=4 without touching any code! Optionally update programs/manifest.json to include title & description in this directory.
